A calm, practical household budget for the Pratama family. Explore a month of rupiah income and spending, adjust a 50/30/20 plan, set savings targets, compare debt payoff methods, and keep recurring bills on track. Transactions, goals, plans, and bill status persist in this browser.

Serve the static app with `node serve.ts`. Run `node main.ts` to copy the app and screenshots to `out/` and generate `dossier.json`.
